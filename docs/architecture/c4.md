## Remaining discrepancies — not silently approved

- The existing model's Advisor-to-Cosmos history access differs from the proposed owner-API design in services.md: resolve through ADR-003.
- Generic non-photo Event Processor cross-store access still needs the broader ADR-012 ownership decision.
- Foundry inference is required by the product baseline but is not explicitly modelled; detailed inference/async views need reconciliation under ADR-014.
- SPA token acquisition/gateway validation detail remains an ADR-009 model task.
- Existing deployment DSL still places web hosting and APIM under App Service; reconcile actual Static Web Apps/platform placement under ADR-011/022 rather than implying those fixes are accepted here.
- Outbox topology, payment adapter/provider and Xero views need their corresponding decisions.
