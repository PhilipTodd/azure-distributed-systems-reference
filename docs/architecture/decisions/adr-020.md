# ADR-020: Xero release placement

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Owner requested Xero; deferral was only a recommendation.

## Options

Launch alongside billing; no integration only by explicit scope decision.

## Proposed decision

Retain Xero in scope; implement after core commercial flow unless owner requires earlier.

## Consequences and verification

OAuth lifecycle, mapping, retries and accounting reconciliation need approval.
