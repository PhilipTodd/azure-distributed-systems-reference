# ADR-009: Customer identity and tank access

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Gateway validation alone cannot enforce ownership.

## Options

Other identity provider; local access projections with revocation design.

## Proposed decision

External ID SPA PKCE flow, backend token validation and per-tank authorisation.

## Consequences and verification

Claim/delegation configuration required; fail-closed dependency affects availability.
