# ADR-004: Data-store responsibilities

Version: 0.5 | Date: 20 October 2026 | Status: Partially Accepted

Owner/approver: human owner/architect. Approval evidence: [authorised decisions, 19 October 2026](../../engineering/authorised-decisions-2026-10-19.md), recording the owner's explicit chat directions and acceptance.

## Context and options

SQL, Cosmos and Blob are baseline inputs. The owner approved Advisor PostgreSQL consolidation; Aquarium schema/shared database placement and /tankId are now accepted in ADR-005/024; other persistence settings remain proposed.

## Accepted change

Advisor uses one PostgreSQL/pgvector instance for jobs, results, quotas, input snapshots and curated reference retrieval, replacing proposed Advisor SQL/AI Search (ADR-015). Photo originals and WebP derivatives follow accepted ADR-016. Aquarium retains Azure SQL; Tracking's Cosmos/Blob baseline remains.

## Remaining proposals

Direct Cosmos .NET SDK for Tracking is now accepted under ADR-028; exact SDK/provider versions, index details, table layouts, consistency and recovery settings remain open. Local transactional outbox mechanics are accepted in ADR-007; /tankId and shared placement in ADR-005/024. Use EF Core SQL and a compatible PostgreSQL provider subject to verification.

## Consequences and verification

Additional engine/provider/migration/restore support; avoid accidental SQL Server assumptions in Advisor. Verify least privilege and independent data ownership.

## Traceability and history

FR-003–011, NFR-006; DEC-09. 0.1 proposed SQL for Advisor; 0.2 records only the explicitly accepted change. Detailed data architecture is not blanket-approved. See [data](../data.md).

## Authorised refinement — 20 October 2026

Accepted ownership clarification: APIs/workers write only their owner's store; Tracking History Store is not a shared event database. Core CRUD commits local state/outbox synchronously. /tankId and shared schema/container placement are now accepted; index/runtime settings remain open.

Evidence: [worker decision record](../../engineering/authorised-decisions-2026-10-20.md).

## Shared database placement acceptance

Aquarium schema/tables/migrations/outbox in platform-owned ReferenceProjectsDb; Tracking-owned containers/indexes/lifecycle in platform-owned Cosmos ReferenceProjects; /tankId accepted. See ADR-005/024 and platform source inventory. This ADR remains Partially Accepted because exact provider/client versions and schema/index/recovery settings are not blanket-approved.

## Accepted persistence client

ADR-028 selects Cosmos .NET SDK directly inside Tracking Infrastructure through narrow Application interfaces, with explicit partitions/batches/continuations/RU diagnostics/change-feed access. Relational Aquarium/Advisor use EF Core 10 with compatible providers. Provider/client exact versions and hosting compatibility are verification gates; no packages installed.
