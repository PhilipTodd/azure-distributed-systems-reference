# ADR-015: Advisor PostgreSQL persistence and curated retrieval

Version: 0.3 | Date: 20 October 2026 | Status: Accepted

Owner/approver: human owner/architect. Approval evidence: [authorised decisions, 19 October 2026](../../engineering/authorised-decisions-2026-10-19.md), recording the owner's explicit chat directions and acceptance.

## Context

The owner requested PostgreSQL experience supporting AI-200 study, and explicitly selected consolidation of proposed Advisor SQL and Azure AI Search.

## Options

Separate Advisor SQL plus AI Search; PostgreSQL retrieval alongside Advisor SQL; one Advisor-owned PostgreSQL database with pgvector.

## Decision

Use one Advisor-owned PostgreSQL database with pgvector on a platform-owned Azure Database for PostgreSQL Flexible Server instance (ownership refined in ADR-024). Relational tables hold jobs, results, quotas and submitted-input snapshots. Reference passages, metadata and embeddings support pgvector retrieval. Replace both proposed Advisor SQL and AI Search; Aquarium retains Azure SQL and Tracking retains Cosmos/Blob.

Photos are not AI context. Curated knowledge and private request snapshots retain separate access/retention semantics.

## Consequences and verification

Avoid two overlapping Advisor data/retrieval services. Verify .NET/provider compatibility, extension/version support, dimensionality, index/filter recall, latency, pooling, sizing, backup/restore and costs. These details remain TBD; acceptance selects the architecture, not a SKU or deployment.

## Traceability

## History

0.1 proposed AI Search; 0.2 supersedes that unaccepted proposal with the owner's accepted PostgreSQL consolidation. No implementation/deployment approval.

## Platform ownership refinement

Advisor still owns jobs/results/quotas/snapshots and curated retrieval data. Shared platform owns server capacity, backups and extensions; this is a hosting ownership refinement, not a return to separate Advisor SQL/AI Search. Platform provision/deployment is a separately owner-requested prerequisite. App compute/data migrations remain staged.
