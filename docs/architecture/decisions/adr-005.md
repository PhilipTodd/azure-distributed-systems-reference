# ADR-005: Cosmos partition strategy

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Panel/state/outbox atomicity needs a common logical partition.

## Options

Time buckets or hierarchical partitioning after feature/transaction review.

## Proposed decision

Start with /tankId; accept only after growth, hotspot and cost tests.

## Consequences and verification

Simple tank queries and transactions; long-lived large tanks need explicit growth headroom.
