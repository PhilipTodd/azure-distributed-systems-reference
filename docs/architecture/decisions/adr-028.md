# ADR-028: Backend, Tracking persistence and frontend technology baseline

Version: 0.1 | Date: 20 October 2026 | Status: Accepted baseline; exact versions/compatibility verification pending

Owner/approver: human owner/architect. Evidence: owner accepted backend baseline/version policy, Cosmos SDK and frontend baseline, then requested documentation update.

## Backend

.NET 10 / ASP.NET Core 10, C# 14, EF Core 10 for relational persistence with compatible SQL Server and PostgreSQL providers. Azure Functions uses .NET isolated worker; verify .NET 10 runtime/extension/hosting compatibility before implementation. Acceptance is not proof the actual shared host supports it.

Pin exact SDK/packages, compatible base images and tooling; no preview dependencies by default. Supported patch updates go through reviewed PRs, compatibility checks and tests.

## Tracking

Use Azure Cosmos DB .NET SDK directly inside Tracking Infrastructure, not EF Core Cosmos provider. Application/Domain use narrowly scoped interfaces. This supports explicit /tankId routing, same-container/partition transactional batch for panel/idempotency/outbox, continuation tokens, request-charge diagnostics and change-feed processing. Aquarium/Advisor remain relational EF Core users.

## Frontend

Angular 22, strict TypeScript and strict template checking, standalone components organised by product feature, client-side SPA on Static Web Apps and no initial SSR. Vitest with Angular TestBed for unit/component tests.

Verify/pin compatible supported Node.js/TypeScript and exact Angular/testing versions when establishing the app; commit lockfile and use reviewed updates/no previews by default. Component/chart libraries remain separate decisions; no selection inferred.

## Verification and scope

Version matrix must cover .NET SDK/runtime/EF/providers, Functions host/extensions, Angular/Node/TypeScript/Vitest and container images. Exact patch versions, provider/library choices and licensing checks remain pending. Do not infer a package version from a framework major or claim a build passed before projects exist.
