# ADR-008: Messaging and compatibility

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Asynchronous messaging is intended; abstraction adoption remains unresolved.

## Options

Dapr now; queues only; alternate broker topology.

## Proposed decision

Service Bus topics by publishing context, command queue for advice, versioned envelopes; defer Dapr.

## Consequences and verification

Explicit event/command distinction and version migration; no global ordering promise.

## Traceability

NFR-004, NFR-010. See [pack index](../../engineering/architecture-pack.md), [service design](../services.md) and [decision register](../../engineering/decision-register.md).
