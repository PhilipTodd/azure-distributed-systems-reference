# ADR-018: Delivery authority

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Requested GitHub Actions differs from observed Azure DevOps pipelines.

## Options

Keep Azure DevOps; dual pipelines with explicit nonoverlapping roles.

## Proposed decision

Migrate deliberately to GitHub Actions and protected environments with immutable image promotion.

## Consequences and verification

One deployer per environment; OIDC/rulesets/checks need actual setup.

NFR-010, NFR-012. See [pack index](../../engineering/architecture-pack.md), [service design](../services.md) and [decision register](../../engineering/decision-register.md).
