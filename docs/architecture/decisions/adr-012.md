# ADR-012: Service-owned workers

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Generic processor currently has unrestricted multi-store relationships.

## Options

Central integration service with narrowly delegated APIs.

## Proposed decision

Assign outbox/photo/advice workers to their data owner; shared platform remains infrastructure.

## Consequences and verification

More workload identities/deployments; ownership and RBAC become explicit.

## Traceability

NFR-007, FR-010–011. See [pack index](../../engineering/architecture-pack.md), [service design](../services.md) and [decision register](../../engineering/decision-register.md).
