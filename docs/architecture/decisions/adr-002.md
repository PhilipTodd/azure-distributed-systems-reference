# ADR-002: Proportionate Clean Architecture

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

The requested portfolio should demonstrate testable boundaries without unnecessary abstraction.

## Options

Vertical slices within bounded services; tightly coupled framework-first code.

## Proposed decision

Keep domain/application independent of HTTP, Azure and persistence; introduce projects/layers where useful.

## Consequences and verification

Requires mapping and dependency checks; avoid boilerplate interfaces with no boundary value.
