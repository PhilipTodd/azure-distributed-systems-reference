# ADR-006: History without full event sourcing

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

The existing label Parameter Event Store does not establish event sourcing.

## Options

Full event sourcing; current state without revision history.

## Proposed decision

Use current records plus immutable revision/audit history.

## Consequences and verification

Simpler queries; explicit corrections/deletion lifecycle still required.

## Traceability

FR-004, FR-008. See [pack index](../../engineering/architecture-pack.md), [service design](../services.md) and [decision register](../../engineering/decision-register.md).
