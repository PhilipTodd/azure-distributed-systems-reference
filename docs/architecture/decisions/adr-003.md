# ADR-003: Store ownership and cross-service reads

Version: 0.1 | Date: 8 October 2026 | Status: Proposed

Owner: human owner/architect. Approver/date/evidence: pending.

## Context

Existing C4 directly links Advisor/processor to other owners' stores.

## Options

Approved projections with explicit freshness/revocation; documented shared access.

## Proposed decision

Use owner APIs initially; no unrestricted cross-service database access.

## Consequences and verification

Synchronous availability coupling; projections remain a later optimisation.

## Traceability

NFR-007, FR-011. See [pack index](../../engineering/architecture-pack.md), [service design](../services.md) and [decision register](../../engineering/decision-register.md).
