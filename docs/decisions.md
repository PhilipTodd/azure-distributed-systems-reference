## Expected shape of an ADR

Each record states the context, the decision, and the consequences in a page that a reviewer can finish in a few minutes. The log above is the index; it is not the decision itself. The ADR’s themselves reside in the docs/architecture/adr project folder. The adr-template-minimal.md file serves as template for future ADR docs.
